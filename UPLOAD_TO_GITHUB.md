# Upload Finance Mastery v0.8 to GitHub Pages

1. Extract the ZIP on your computer.
2. Open the existing Finance Mastery GitHub repository.
3. Upload **all files and folders inside the extracted folder** to the repository root.
4. Replace the old versions of `index.html`, `app.js`, `data.js`, and `styles.css`.
5. Make sure the new root file **`annotations.js`** is also uploaded.
6. Keep the `.webp` images, `assets/`, `content/`, and `.nojekyll` in the repository root structure.
7. Commit the changes.
8. Wait for GitHub Pages to redeploy, then hard-refresh with `Ctrl + F5` if needed.

Your existing GitHub Pages URL does not need to change.

## Verify the annotation feature
Open any lesson → select one sentence → the black floating toolbar should immediately show **Highlight · Comment · Flashcard** plus four color squares.

Annotations are stored in browser localStorage on the same GitHub Pages domain. Use **Notes & Highlights → Export backup** before clearing browser storage or moving devices.
