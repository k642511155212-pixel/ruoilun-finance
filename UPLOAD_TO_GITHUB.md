# Upload v0.5 to GitHub Pages

1. Download and unzip the v0.5 package.
2. In your existing GitHub repository, upload/replace the files from this folder.
3. `index.html`, `app.js`, `data.js`, `styles.css`, `.nojekyll`, and `404.html` must stay in the repository root.
4. Upload the `assets/` and `content/` folders too.
5. Commit the changes.
6. If GitHub Pages is already configured as **Deploy from a branch → main → /(root)**, do not change the Pages settings. The same site URL will update automatically after the Pages deployment finishes.

You do not need to upload the ZIP itself to the repository.
