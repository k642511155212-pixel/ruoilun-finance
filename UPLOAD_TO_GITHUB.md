# Upload Finance Mastery v0.7 to GitHub Pages

1. Extract the ZIP on your computer.
2. Open the existing Finance Mastery GitHub repository.
3. Upload **all files and folders inside the extracted folder** to the repository root.
4. Replace the old versions of `index.html`, `app.js`, `data.js`, and `styles.css`.
5. Keep the image `.webp` files, `assets/`, `content/`, and `.nojekyll` in the repository root structure.
6. Commit the changes.
7. Wait for GitHub Pages to redeploy, then hard-refresh with `Ctrl + F5` if needed.

Your existing GitHub Pages URL does not need to change.

Important: annotations are stored in browser localStorage. Updating site files on the same GitHub Pages URL should preserve them. Use the new **Export backup** feature before clearing browser storage or moving to another device.
